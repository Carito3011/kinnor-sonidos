# Kinnor — sonidos descargables

Paquetes de sonido que Kinnor Studio descarga la primera vez (así la app queda ligera).
Se publican como *Releases* de este repositorio.

## Kinnor Orquesta 2 (`orquesta-2`)

`kinnor-orquesta-2.sf2` — 47 sonidos de orquesta real, estéreo, 44,1 kHz:
cuerdas (violines I y II, violas, cellos, contrabajos, solistas, pizzicato, trémolo, spiccato), metales y maderas
con capas de intensidad, arpa, percusión afinada, timbales, coro…
Cada sonido trae su versión "legato" (banco 211) y su articulación corta (banco 212) para que Kinnor las use solas.
